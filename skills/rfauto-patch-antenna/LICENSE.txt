## FAQ

**Q: Does rfauto's MIT license conflict with openEMS's GPL-3.0?**

A: No. rfauto's main process never imports openEMS or CSXCAD Python bindings. These GPL-licensed
bindings are used only within child processes spawned by `simulation.py` (subprocess execution).
The rfauto repository itself contains no GPL code. Users compile bindings separately from the
openEMS source repository.

**Q: Can I use rfauto commercially?**

A: Yes, rfauto itself is MIT-licensed. However, you need valid licenses for any commercial EDA
software you use with it (Ansys AEDT/HFSS, Keysight ADS). rfauto does not provide or facilitate
any license circumvention.
