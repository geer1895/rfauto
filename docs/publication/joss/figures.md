## Rules for all figures

1. **Reproducible**: a single command regenerates the figure from archived
   inputs; the command and input archive hash are recorded here at submission.
2. **Public-safe**: inputs and outputs carry no private paths, credentials,
   or non-shareable data; every figure passes the pre-upload review
   (three-question provenance check) before submission.
3. **Honest**: no cherry-picked runs; the example campaign is declared and
   archived alongside the figure. Error bands and failed-gate markers are
   shown, not cropped.
4. **Accessible**: color palettes checked for dark/light legibility and
   colorblind safety; text ≥ 7 pt at final width.
